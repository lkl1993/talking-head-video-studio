# 口播视频智能剪辑 V1.3.0

**免费分享一套从真人口播到剪映专业版草稿的 AI 剪辑工作流。**

这是一个面向视频创作者的 Codex Skill，可以帮助你完成：

- 真人口播粗剪
- 自动分镜与画面规划
- AI 动效制作
- 背景音乐与动作音效
- 多轨声音混合
- 生成可编辑的剪映专业版草稿

## 如何安装

1. 下载仓库中的 V1.3.0 ZIP 安装包。
2. 解压后打开「先读我」。
3. 根据自己的系统选择 macOS 或 Windows 安装教程。
4. 将自己的口播视频放入项目文件夹。
5. 在 Codex 中调用 `$talking-head-video-studio`。

## 系统要求

- Codex
- 剪映专业版
- Python 3.12
- Node.js 24 LTS
- FFmpeg / FFprobe
- Chrome 浏览器

## 验证情况

macOS 已完成动效渲染、粗剪、三轨音频及模拟草稿归档验证。

Windows 已完成兼容分支检查，但原生安装及剪映实际打开、保存、重开仍需 Windows 真机验证。
